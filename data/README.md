# data/

## ExtensionJson.json

A bundled snapshot of the [extjsonuploader](https://extjsonuploader.toolforge.org/)
dataset: a JSON mapping of MediaWiki extension/skin names to their metadata
(git repository URL, description, version constraints). It is used by
`canasta extension|skin add` to resolve names into git remotes without
needing network access at invocation time.

Provenance and licensing:

- Source: <https://extjsonuploader.toolforge.org/ExtensionJson.json>
  (User-Agent `canasta-cli`).
- The underlying content derives from MediaWiki.org extension/skin pages
  ([CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)), gathered
  by the Wikimedia Toolforge `extjsonuploader` tool.
- The snapshot is regenerated by running `make refresh-extension-json`, which
  downloads the current dataset and replaces this file atomically after
  validating that it parses as JSON.

The bundled snapshot is used in preference to the live dataset: at runtime the
resolver reads this file first and only downloads the live URL if a name is
absent from the snapshot. A stale snapshot therefore silently wins over the
live dataset, so `make refresh-extension-json` is load-bearing — run it to pick
up upstream additions, renames, or repository-URL changes rather than relying
on the live fallback.
